# Examples

This directory contains sanitized demonstration assets. These files are safe
for demos, onboarding, and regression checks, but they are not templates.

## Projects

- `projects/hardware-platform-demo.yaml` is a sanitized complex hardware
  project derived from a real project shape. It demonstrates DAG scheduling,
  risk scoring, prompt generation, requirements traceability, and close-gate
  checks.

## Rule

Use examples to understand behavior. Use `flows/` and `tracker/templates/` to
create new projects.
